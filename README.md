# Panel DJ (APK con GitHub)

Solo 2 archivos: index.html y build-apk.yml

1. Crea un repositorio nuevo en github.com.
2. Add file > Upload files: sube index.html. Commit changes.
3. Add file > Create new file. Nombre: .github/workflows/build.yml
   Pega el texto de build-apk.yml. Commit changes.
4. Pestana Actions: espera la palomita verde (5 a 10 min).
5. Abre la ejecucion, baja a Artifacts, descarga panel-dj-apk, descomprime e instala app-debug.apk.
